# 디자인 토큰

출처는 GitHub [DejaFix/DejaFix](https://github.com/DejaFix/DejaFix) 프론트엔드(`dev` 브랜치) 하나뿐이다. CSS 값과 불러오는 순서를 그대로 옮겼다.

| 파일                    | 내용                                            | 원본                                |
| ----------------------- | ----------------------------------------------- | ----------------------------------- |
| `src/styles/tokens.css` | 기본 토큰(라이트) + 다크 토큰                   | DejaFix `tokens.css`                |
| `src/styles/global.css` | 기본 요소·컴포넌트 클래스                       | DejaFix `global.css` (+ 신규 Modal) |
| `src/styles/theme.css`  | 인디고 팔레트 + 모서리 0 (라이트 토큰 덮어쓰기) | DejaFix `theme.css`                 |
| `src/styles/shell.css`  | 어두운 사이드바·상단바·사용자 메뉴              | DejaFix `shell.css`                 |

| 폭       | 바뀌는 것                                                                |

| ≤ 1500px | 오른쪽 패널이 열려 있으면 상단바 여백·단축키 표시 줄임                   |
| ≤ 1280px | 사용자 메뉴 이름 숨김                                                    |

| ≤ 900px  | 사이드바 → 가로 메뉴, 검색칸 숨김, 오른쪽 패널 전체 폭, 페이지 여백 16px |

## DejaFix와 다른 점

| 항목                    | DejaFix                             | 이 템플릿                                                     | 이유                                                  |
| ----------------------- | ----------------------------------- | ------------------------------------------------------------- | ----------------------------------------------------- |
| 모서리 0 방식           | `* { border-radius: 0 !important }` | 토큰 `--radius-*: 0` (`--radius-pill`, `--radius-round` 포함) | 화면 결과는 같고, 토큰만 바꾸면 둥글게 되돌릴 수 있음 |
| 버튼·검색·세그먼트 바탕 | `#fff`                              | `var(--surface)`                                              | 라이트에서는 같은 값. 다크에서 흰 버튼이 되지 않음    |
| 상태색 이름             | `--sev-*`, `--risk-*`               | `--success/warning/danger/info`                               | 도메인 이름 제거. 값은 같음                           |
| Modal                   | 없음                                | `.modal*` 클래스, `--overlay` 토큰                            | 신규 (승인됨)                                         |

## DejaFix 대비 예외 (컴포넌트 동작)

화면 모양·CSS는 DejaFix와 같고, 아래 동작만 더했다(사람이 승인한 예외).

| 컴포넌트         | 더한 것                                       | 이유                                                              |
| ---------------- | --------------------------------------------- | ----------------------------------------------------------------- |
| SearchBox        | 한글 입력(글자 조합) 중 Enter는 검색하지 않음 | 조합 중 Enter는 글자 확정이라, 검색이 먼저 실행되는 문제를 막는다 |
| SegmentedControl | 선택된 버튼에 `aria-pressed`                  | 어느 버튼이 선택됐는지 스크린리더가 알 수 있게                    |
| Skeleton         | `aria-label="불러오는 중"`                    | 빈 상자만으로는 스크린리더가 아무것도 읽지 않는다                 |
| Collapsible      | 머리 버튼에 `aria-controls` (펼치는 영역 id)  | 버튼과 펼치는 영역의 관계를 스크린리더에 알린다                   |

## 템플릿 작성 시 정한 기본값

DejaFix에 해당 값이 없어 템플릿을 만들 때 Claude가 정한 값이다. 바꿔야 하면 DejaFix처럼 마크업을 직접 쓴다.

| 컴포넌트    | 기본값                                     | DejaFix                                                    |
| ----------- | ------------------------------------------ | ---------------------------------------------------------- |
| ProgressBar | 막대 색 `var(--primary)`, 오른쪽 값 퍼센트 | 화면마다 막대 색(`style.background`)과 값 글자를 직접 지정 |

## 알려진 이슈 (DejaFix 원본 그대로)

- `.info-tip` 말풍선은 숨어 있을 때도 300px 자리를 차지해서, 화면 오른쪽 가까이에 두면 좁은 화면에서 가로 스크롤이 생긴다.
- 다크 모드에서 `.field input`·`.select` 바탕은 지정되어 있지 않아 브라우저 기본값을 따른다.
